核心攻关出发点： 一方面，单靠【一筋】光纤应变或日常人工巡查均不足以可靠预警，须由【一机】统筹“规-建-管-养”全生命周期数据耦合研判，解决误漏报与响应滞后问题；另一方面，针对传统公路数字化项目纯投入、基础设施防灾感知长效运维资金承压的共性难题，课题依托【一机】联动百度地图与奇瑞绿能零碳充储微网，将路网感知转化为需量降费与避险导流运营增量，探索以交能融合收益反哺防灾运维的可持续路径。

01 梅大高填方路基灾变工程复盘与响应对比

2024年5月1日凌晨 2:00，梅大高速茶阳段 17.9 米路基自深层基底整体剪切垮塌，导致 23 辆车坠落、48 人遇难。该段为山区沟谷高填方路基（非天然挖方边坡），长期受强降雨渗流与重货交变荷载影响，雨水聚集于填土与原地面接触带。

1. 单靠巡查记录无法定性 日常养护巡查记录已登记“路面积水、排水不良”，但未关联地质、竣工暗涵与沉降台账，仅按普通病害留存。
2. 缺全周期数据与力学研判 单一表象或孤立传感极易误判，缺乏“规-建-管-养”数据支撑的水力学研判，未能识破地下基底饱和与剪切贯通前兆。
3. 内网数据未接通公众地图 隐患停留在内部台账，未与公众地图打通，雨夜在途车辆百度地图仍显示正常通行，缺少触达司机的阻断手段。

05 课题实施风险分析与应对措施
风险类别 核心风险点 务实应对与成本控制措施
1. 公共数据合规出域
最大核心风险		 日常养护巡查记录、“规-建-管-养”底表及桥隧结构安全状态均属交通公共敏感数据，直接推向百度地图及外部充储场站存在数据安全与授权红线，原始数据严禁直接出内网。

• “原始数据不出域，结果指令脱敏出”：依托【一机】在广东省交通集团有限公司内网本地计算推理，原始图纸与巡查原文不离内网；

• 仅将脱敏后的“高危桩号阻断状态、电子围栏及微网保供调度指令”，经授权通道合规分发至百度地图 API 与奇瑞绿能微网调度端。
2. 研发成本控制与商业协同风险
100万预算与多方约束		 共同研究课题经费仅 100 万元，若重造底层平台或单独土建易导致超支；同时涉及高速业主、微网运营与图商多方联动，商务分润协议落地周期较长。

• 全链路复用降本：【一机】直接复用已定型 AIP 软件内核向 AI硬件 移植，【一筋】借力集团大中修队伍与奇瑞绿能大槐既有充储微网，省去重资产土建开支；

• 分步试点跑通闭环：先依托大槐示范区签署试点协议，优先跑通“大中修植入 + 需量削峰省电费”及百度 API 联调，再逐步拓展车队清分与保司风险减量合作。
3. 充储设施产权归属与建设出资周期风险
高速固定资产 vs 社会资本		 服务区充储微网建在高速公路用地红线内，建成后属于高速公路固定资产，社会资本（如奇瑞绿能）不能直接投资持有；但若完全由高速集团自有资金出资，立项审批、招采与预算拨付周期漫长（通常 1～2 年），难以匹配重货充电需求与课题进度。

• 委托代建 + 收益分期回购：由广东省交通集团有限公司作为资产所有方，委托奇瑞绿能按约定标准垫资代建充储微网，集团以充电运营收益分期回购，产权始终归属集团，合规不触红线；

• 特许运营权授权模式：集团授予奇瑞绿能约定年限的服务区充储微网特许运营权，奇瑞绿能负责建维并自担经营风险，集团收取固定使用费或收益分成，期满资产无偿移交；

• 课题先行以小撬大：本课题 100 万经费仅用于【一机】调度联调与感知示范、不涉及充储土建重资产投资，先行用大槐真实节电与引流数据支撑集团加速立项或代建协议落地。
